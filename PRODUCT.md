# DalelCheck

Original bounded v0.1; reference15 Gumloop is inspiration only. Operate extension of our own KoshiMap/BekitChange Shared Work Cabinet, preserving native navigation/forms/disclosures, navy/pale/green system and user data elsewhere.

Admin publishes 1–12 ordered requirements with both authored RU/KK texts. Staff freezes one synthetic plain-text document (language ru/kk,1–12000 UTF-16 units after outer trim), starts an owner worksheet with immutable publication/document snapshots and manually assigns each requirement supported, missing or conflicting. Supported uses one precise contiguous span; conflicting uses two ordered disjoint spans; missing has no spans. Server extracts exact quotes from zero-based UTF-16 start inclusive/end exclusive, rejecting split surrogate pairs and blank spans. No normalization, case folding, translation or semantic judgement. Reused spans across requirements allowed. Each finding needs a manual rationale. Exact text is proof of textual containment only, not truth, sufficiency, absence or actual contradiction.

Only worksheet author edits findings and explicitly seals one whole report after every published requirement has exactly one finding. complete means all marked supported; otherwise needs_evidence. It does not mean commercial/legal validity. Incomplete worksheet cannot seal. Final report snapshots entire document, publication, exact findings/quotes/versions and digest, actor/time; no edit/reopen/reversal. Final findings freeze. Document and publication immutable. Checklist edits/version/requirement archive affect future publication only; incomplete drafts permitted. Global revision in BEGIN IMMEDIATE protects all writes, including unrelated edits; global UUID on document/worksheet/report refuses replay. No HTTP preview/hash requirement or proof of human reading. Admin cannot bypass author. Source/pub/checklist archive blocks new worksheets, existing worksheets continue from snapshots; worksheet archive closes unfinished work; findings/reports cannot archive. All staff share one area, no tenant isolation.

Unsigned JSON checks consistency, not authenticity/account identity/historical rights; users/auth/audit excluded, restore empty area only; HTTP2MB, larger full backups require consistent SQLite. Admin session revocation is available; UI password reset/account disabling is absent. No Gumloop code/brand/integration, AI/LLM, OCR/files/upload extraction, external API/secrets/messages, real documents, legal advice, customer outcomes or payments. Only synthetic data.
